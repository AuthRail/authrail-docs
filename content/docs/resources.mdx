Use the AuthRail workspace to configure your organisation and review its
records. Use the public sidecar and SDK repositories when connecting your own
application. They have different roles: installing a library does not create
your workspace or its rules.

## Open AuthRail

<a href={AUTHRAIL.workspaceOrigin}>Sign in to the AuthRail workspace</a> and select
your organisation. If you cannot manage AI systems or publish Rails, ask your
workspace administrator for the access needed for your task.

New to the product? Begin with the [introduction](/docs). Ready to connect code?
Follow [your first application](/docs/getting-started).

## Install an SDK

The SDKs are published as version **{AUTHRAIL.releases.sdkVersion}**. Use the
installation guide for your language, then keep that version in your
application's dependency files.

| Your application | Published package | Setup guide |
| --- | --- | --- |
| JavaScript or TypeScript | <a href={AUTHRAIL.packages.node}>@authrail/sdk-node on npm</a> | [Node setup](/docs/node) |
| Go | <a href={AUTHRAIL.packages.go}>authrail-sdk-go on pkg.go.dev</a> | [Go setup](/docs/go) |
| Python | <a href={AUTHRAIL.packages.python}>authrail on PyPI</a> | [Python setup](/docs/python) |

## Get the sidecar and source code

The sidecar is a separate service, not part of the SDK package. Use the
[Docker guide](/docs/docker) to build and run a container, or the
[native guide](/docs/native) for a downloaded executable. Native archives and
checksums are available from the <a href={`${AUTHRAIL.repositories.sidecar}/releases/tag/v${AUTHRAIL.releases.sidecarVersion}`}>sidecar release</a>.

| Repository | Use it to… |
| --- | --- |
| <a href={AUTHRAIL.repositories.sidecar}>AuthRail Sidecar</a> | Inspect the local rule checker, Docker configuration and OpenShell example. |
| <a href={AUTHRAIL.repositories.node}>Node SDK</a> | Read the JavaScript and TypeScript adapter source and examples. |
| <a href={AUTHRAIL.repositories.go}>Go SDK</a> | Read the Go adapter source and examples. |
| <a href={AUTHRAIL.repositories.python}>Python SDK</a> | Read the Python adapter source and examples. |
| <a href={AUTHRAIL.repositories.docs}>Documentation</a> | Read this site's source or report a documentation issue. |

The [compatibility guide](/docs/compatibility) explains how to record the SDK
and sidecar versions you run and check the paths your application protects.

## NVIDIA OpenShell

If your agent runs in OpenShell, use the [AuthRail integration

<a href={AUTHRAIL.references.openshell}>NVIDIA documentation</a> and

## Integration references

Our integration research draws on <a href={AUTHRAIL.references.openappa}>OpenAPPA's
work on checking tool calls and tool results</a>. AuthRail's SDKs, rules and approval
flow have their own implementation. Follow the AuthRail guides for your integration.

## Report a problem safely

Include the component version, command, expected result and a redacted error in
an issue on the relevant repository. Keep credentials, customer source text and
private logs out of public issues.
